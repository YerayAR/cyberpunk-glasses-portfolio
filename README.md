# Cyberpunk Glasses Portfolio

Static portfolio export of a WordPress storefront project.

## What is in this repo

- `dist/`: static site deployed to Vercel
- `theme-source/`: WordPress theme source used to build the project
- `build-static.mjs`: static export generator

## Local build

```bash
npm run build
```

## Notes

- The public Vercel deployment is a static portfolio version.
- The original project was built as a custom WordPress theme.
- Checkout is simulated on the static deployment and stores state in the browser only.
